# Trading News Agent 4

English-only customer interface and documentation: guided setup, manual symbol selection, JSON for other agents, Pera or a dedicated automatic wallet, two x402 resources, explainable GDELT news ranking and interrupted-purchase recovery.

Extract the complete ZIP and open INSTALL.bat on Windows or run bash install.sh on Linux/WSL. Internet access is required. Customers do not need news or paid AI API keys.

Before distributing this as a production service, deploy API v4 to the existing Render service and validate a real Pera purchase. See DELIVERY_STATUS.md and DEPLOYMENT.md. This release does not claim those checks are already complete.
