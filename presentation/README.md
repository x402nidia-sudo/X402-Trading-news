# Trading News — English presentation

[Watch the English video](Trading_News_Agent_v4_EN.mp4)

Duration: 100 seconds. Format: H.264 MP4, 1280 × 720, 24 fps. All on-screen text and the embedded English subtitle track are in English. A separate `.srt` file is included. This is a silent visual explainer, without narration.

The video covers installation, guided configuration, Pera approvals, the 49-symbol catalog, both 0.10 USDC purchases, explainable selection, JSON calls and interrupted-purchase recovery. The example headline is explicitly fictional. No real transfers occur in this recording. Backend deployment and a real Pera purchase remain pending.

`render_video.py` contains the editable source. Regeneration requires Python with Pillow, FFmpeg and the DejaVu fonts at the Linux paths used by the script. These tools are not needed by customers to install or run the agent.
